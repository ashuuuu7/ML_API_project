# ML Placement Prediction API

Machine Learning Placement Prediction System built using FastAPI, Scikit-Learn and XGBoost.

## Features

- Placement Prediction
- FastAPI Backend
- REST API
- Swagger Documentation
- Frontend Interface

## Tech Stack

Python
FastAPI
Scikit-Learn
XGBoost
Pandas
NumPy

## Run

pip install -r requirements.txt

uvicorn ML_API_Project:app --reload
